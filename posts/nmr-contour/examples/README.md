## Murray et al. reference spectrum

CC_2D-U-FUS.ucsf is the unmodified deposited 2D carbon-carbon spectrum of uniformly labeled FUS-LC fibrils. The data-list.pdf table calls it CC-2D-U-FUS.ucsf (hyphen instead of the archive filename's underscore). The table specifies 25 ms DARR, 17.5 T, 17 kHz MAS. File shape: 2048 x 4096.

Dataset contributors: Robert Tycko, Dylan Murray, Masato Kato, Steven McKnight, Yi Lin, Ivan Hung, Kent Thurber. Dataset DOI: https://doi.org/10.17632/rxbh442x2g.1 . Related paper: Murray et al., Cell 171, 615-627 (2017), https://doi.org/10.1016/j.cell.2017.08.048 . License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . No modifications to spectrum or PDF. Retrieved 2026-10-15. Both downloaded SHA-256 values match Mendeley metadata; accompanying .source.json files preserve original filenames, checksums, file IDs, and URLs.

Startup and the Reload Murray et al. 2017 example data link load both spectra plus BMRB 30304 assignments from this same study as separate dataset entities. No automatic shift correction is applied, and residue labels preserve BMRB Comp_index_ID rather than full-length FUS numbering.

CC-2D-N112-FUS.ucsf is also included unmodified, with its source metadata and verified SHA-256. It is full-length FUS-LC with residues 1–111 labeled and an S112C ligation-site substitution (Murray et al., Fig. 3), not a truncated protein. Same dataset contributors, DOI, and CC BY 4.0 license above. The pair is loaded by default, with positive contours only.
